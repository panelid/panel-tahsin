## Variant: Bold Split

### Design stance
Hero split (teks kiri, panel progres kanan), teal solid background, card grid track, action-first. Vibe kayak Linear/Stripe.

### Key choices
- Layout: 2-col hero split, grid 3-col track, 3 step
- Typography: Inter 800 (bold), tight tracking
- Color: teal solid header, white body
- Interaction: card hover border teal, scale button

### Trade-offs
- Strong: jelas, modern, profil progres kelihatan langsung
- Weak: teal full di atas bisa terlalu berat buat sebagian

### Best for
Yang mau lihat "dashboard/progres" langsung, action jelas.
