## Variant: Calm Editorial

### Design stance
Minimalis, banyak whitespace, serif heading (Newsreader), satu kolom center. Vibe tenang kayak Medium/Notion.

### Key choices
- Layout: single column, center, max-width 720px
- Typography: Newsreader serif untuk heading, Inter body
- Color: krem putih (#fcfbf9), accent teal
- Interaction: link halus, gak ada card grid

### Trade-offs
- Strong: kalem, terasa premium, fokus ke bacaan
- Weak: gak ada visual mencolok, action kurang menonjol

### Best for
Konten-forward, orang yang cari ketenangan (cocok islami).
